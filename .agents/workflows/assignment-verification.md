# Assignment Verification Workflow

Create a requirement matrix.

For every assignment requirement:

Requirement
↓
Implementation Location
↓
Verification Method
↓
Status

Verify:

- template
- selection
- canvas editing
- code editing
- viewport behavior
- AI demo
- proposal review
- partial acceptance
- history
- recovery
- persistence
- reset
- accessibility
- tests
- documentation

Do not mark requirements complete without evidence.
