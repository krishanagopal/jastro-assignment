# Architecture Design Workflow

Before building major UI:

1. Define canonical template model.
2. Define stable IDs.
3. Define editable properties.
4. Define selection model.
5. Define viewport model.
6. Define responsive resolution.
7. Define edit command.
8. Define validation.
9. Define commit boundary.
10. Define AI proposal model.
11. Define revision history.
12. Define recovery.
13. Define persistence.

Only then begin implementation.
