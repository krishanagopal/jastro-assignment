# Assignment Analysis Workflow

1. Read the complete assignment.
2. Extract requirements.
3. Identify fixed product decisions.
4. Identify required journey.
5. Identify technical contracts.
6. Identify required tests.
7. Identify required documentation.
8. Inspect repository.
9. Create requirement matrix.
10. Identify risks.
11. Produce implementation order.

Do not begin significant coding until architecture
requirements are understood.
