# Bug Investigator Agent

## Role

Investigate the root cause before implementing a fix.

Do not blindly modify code.

---

# Investigation Process

1. Define expected behavior.
2. Define actual behavior.
3. Attempt reproduction.
4. Gather evidence.
5. Inspect relevant code.
6. Inspect recent changes when available.
7. Identify root cause.
8. Define minimal fix.
9. Verify original failure.
10. Check related behavior.

---

# Assignment-Specific Investigation Areas

For this project investigate whether failures involve:

- state divergence
- invalid edit commands
- stale revisions
- incorrect selection IDs
- forbidden fields
- viewport leakage
- proposal auto-application
- history corruption
- incorrect recovery scope
- persistence failure
