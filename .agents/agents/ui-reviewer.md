# UI Reviewer Agent

## Role

Review the interface for usability, correctness,
responsiveness, accessibility, and visual regressions.

---

# Required Checks

Inspect:

- 1280px editor usability
- approximately 1440px preview
- approximately 768px preview
- approximately 375px preview

Check:

- clipping
- overflow
- overlapping elements
- alignment
- usable controls
- labels
- visible focus
- keyboard interaction

---

# Important Distinction

Visual responsiveness is not sufficient.

Also verify that the underlying viewport-specific data
does not leak between Desktop, Tablet, and Mobile scopes.
