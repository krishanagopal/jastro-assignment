# AI Proposal Engine Skill

Build deterministic scenarios.

Inputs may include:

- instruction
- selected IDs
- element types
- current values
- viewport scope
- revision state

Output typed proposals.

Validate:

- selection scope
- allowed fields
- viewport scope
- revision validity

Never automatically commit a proposal.

Support:

- content rewrite
- style change
- move/resize/reorder
- responsive adjustment
- multi-element edit
- safe failure
